# Netflix Clone

A responsive Netflix-inspired website built to practice frontend development, UI design, layouts, and responsive web development.

🌐 **Live Demo:** [Netflix Clone](https://piyush07d.github.io/Netflix-Clone/)

---

## ✨ About

This project is a frontend recreation inspired by the Netflix interface.

The main goal of this project was to practice building a modern streaming-platform UI using HTML and CSS while focusing on layout, typography, spacing, and responsive design.

---

## 🚀 Features

- 🎬 Netflix-inspired user interface
- 📱 Responsive design
- 🖼️ Movie/show showcase
- 🔐 Login interface
- 🎨 Dark-themed UI
- 📐 Responsive layouts for different screen sizes
- ⚡ Lightweight frontend implementation
